============================================================
{{ .Chart.Name }} – Common Templates Library
============================================================

This chart is a reusable library of template helpers for other Helm charts.
It does NOT deploy any Kubernetes resources by itself.

------------------------------------------------------------
What this chart provides
------------------------------------------------------------

- Standardized naming helpers:
  - "myorg.name"
  - "myorg.fullname"
  - "myorg.chart"

- Standardized labels and selectors:
  - "myorg.labels"
  - "myorg.selectorLabels"

- Hooks for organization-wide labels/annotations:
  - .Values.commonLabels
  - .Values.commonAnnotations

Refer to this chart's README for the complete list of helpers and usage examples.

------------------------------------------------------------
How to use in application charts
------------------------------------------------------------

1. Declare as a dependency in your Chart.yaml:

   dependencies:
     - name: myorg-common
       version: 1.x.x
       repository: oci://your-registry/helm-charts

2. Use the shared helpers in your templates, for example:

   meta
     name: {{ include "myorg.fullname" . }}
     labels:
       {{- include "myorg.labels" . | nindent 6 }}

   spec:
     selector:
       matchLabels:
         {{- include "myorg.selectorLabels" . | nindent 8 }}
     template:
       meta
         labels:
           {{- include "myorg.labels" . | nindent 10 }}

3. Optionally pass organization-wide labels/annotations via values:

   commonLabels:
     myorg.io/team: "platform"
     myorg.io/env: "dev"

------------------------------------------------------------
Notes
------------------------------------------------------------

- This chart is intended to be owned by the platform team.
- Application teams should consume its helpers but should not fork or modify them locally.
- Breaking changes MUST be released under a new major version and communicated to all dependent charts.
